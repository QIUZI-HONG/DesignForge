# 08: 版本恢复 Toast 撤销

**What to build:** 用户在版本历史「确认恢复」后，底部 Toast 除「已恢复所选版本」外附带「撤销」动作，点击即回到恢复前状态——误恢复一键回退，不用再进版本历史找「回滚前自动保存」。撤销复用顶栏撤销的**同一条命令 id**（入口与快捷键不漂移的既有纪律）。Toast 本体的底部居中胶囊形态与自动消失时机保持不变。

**Blocked by:** None (can start immediately)

**Status:** done（已并入 ux-audit-remediation 9b69956，浏览器项待复核）

- [x] 组件测试：恢复版本 Toast 含「撤销」按钮，点击触发与顶栏撤销同 id 的命令
- [x] 组件测试：其他 Toast（复制代码等）不受影响；自动消失时机不变
- [ ] 浏览器实测：恢复 → 撤销 → 文档回到恢复前内容（与「回滚前自动保存」路径兼容）
