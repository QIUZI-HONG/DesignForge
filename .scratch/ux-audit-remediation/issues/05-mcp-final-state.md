# 05: MCP 审批终态留存

**What to build:** 审批人在确认或拒绝 MCP 提案后，能看到**持久的**终态反馈：确认条显示「已批准/已拒绝 + 桩注（未产生真实写入）」并保留，直至新提案替换或 TTL 到期——当前 ack 200 后确认条在约 150ms 内整体消失，审批人不知道自己的决策是否被记录。一次性 token 语义、审计字段、桩角标全部不变（MCP 确认条在本票范围内仍是桩，只修结果态可见性，不改桩语义）。过期态现有文案「已失效（超时未确认）需重新发起 dryRun」保持。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 确认状态机纯测：ack 成功后进入稳定终态，不被立即清空；新提案替换时重置（既有行为保留）
- [ ] 组件测试：批准/拒绝后终态文案（含桩注）持续可见；倒计时区域不再显示
- [ ] 组件测试：过期态、失效态、ack 复用 403 的既有行为不回退
- [ ] 浏览器实测：经 dryRun 提案投递 → 确认 → 终态停留可见
