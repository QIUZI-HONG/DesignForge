# 11: 图层面板交互批

**What to build:** 图层面板补齐清单 C3 要求的四个缺口：① 拖拽排序真实生效（走命令栈事务，可撤销，保存后持久）；② 重命名为空提交时给出「名称不能为空」类提示并回退（当前静默不变）；③ 名称超长钳制到与新建文件一致的 64 字符上限（当前 5000 字被接受）；④ 图层行内提供显隐/锁定控件（当前无入口）。右键菜单、双击重命名、选中同步等既有能力不回退。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 组件测试：空名提示回退、64 字符钳制、显隐/锁定控件状态切换
- [ ] 命令栈纯测：拖拽排序为可撤销事务，撤销后顺序还原
- [ ] 浏览器门禁挂点：拖拽重排后图层顺序变化并随保存持久（刷新后保持）
- [ ] 浏览器实测：拖拽排序 + 显隐/锁定 + 重命名三类操作全链可用
