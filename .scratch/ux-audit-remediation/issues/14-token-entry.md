# 14: Token 添加入口

**What to build:** 资产面板的 Token 分段获得添加/管理入口：用户可新建令牌、命名、设值，令牌进入文档数据并可在 Inspector/导出侧被引用——资产面板不再只是只读展示（当前组件与 Token 数据为空且无添加入口）。组件系统（创建组件/实例/变体）**不在本票**（那是单独的能力缺口，spec 已列 Out of Scope）。搜索与空态既有行为不回退。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 引擎纯测：令牌创建入文档数据、序列化往返、与既有令牌解析（别名/环检测）兼容
- [ ] 组件测试：添加入口、命名校验（重名/非法字符）、空态消失
- [ ] 浏览器实测：添加令牌 → 保存 → 刷新后仍在；Inspector 可见
