# 06: 错误面中文化

**What to build:** 三个错误面（AI 抽屉、顶栏保存态、市场错误态）的网络层失败统一呈现为「中文人话 + 可执行下一步 + 可折叠技术详情（含错误码）」——不再是浏览器原文 `Failed to fetch` / `TypeError: Failed to fetch`。人话口径示例：「无法连接本地服务——请确认 daemon 已启动」，并提供与场景匹配的下一步（重试 / 去诊断 / 检查配置）。技术详情折叠后保留原始 message 与错误码，供报障引用。全部文案入 zh-CN 目录（ADR-0003）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 组件测试：AI 抽屉失败态显示中文人话 + 下一步动作，技术详情折叠可见原始错误
- [ ] 组件测试：保存失败态同样命中（杀 daemon 实测「保存失败：Failed to fetch」→ 人话 + 下一步）
- [ ] 组件测试：市场断网错误态命中，重试恢复后回正常态（既有能力不回退）
- [ ] 三面错误文案均来自 zh-CN 目录；无裸英文技术串直接暴露
- [ ] 既有成功路径（市场断网→恢复→重试成功）回归通过
