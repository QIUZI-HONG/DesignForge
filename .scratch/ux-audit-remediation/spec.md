## Problem Statement

2026-10-30 的全功能体验巡检（`docs/quality/ux-audit-2026-10-30.md`，54 项 = Y 35 / 部分 17 / N 2）显示：产品的编辑器内核扎实，但三处信任损伤与一批交互缺口让「能用的编辑器」看起来像半成品——

1. **AI 生成在浏览器里必然失败**：AI 抽屉的流式响应不带 CORS 头（非流式带），浏览器拦截后用户只看到英文 `Failed to fetch`，重试是死循环；daemon 侧精心实现的降级响应与建议清单从未有机会呈现。
2. **AI 承诺与交付不符**：首页承诺「初稿与图层结构」，实际只回一段文字且无任何应用动作；步骤流里的「校验/编译」并未发生却显示已完成；降级态声称「由本地模板生成」而全仓不存在模板生成器（降级内容恒为空串）。
3. **命令面板（P0）裸奔**：样式表未被引入（25 条规则全部未生效），浮层无卡片无遮罩压在画布上；清单要求的 ⌘K 全局键位不生效；速查卡渲染在视口外。

其余体验缺口：MCP 审批结果一闪而过、错误面漏英文技术串、禁用按钮多数无原因提示、Toast 无撤销、图层拖拽/标尺参考线/双击文本编辑等交互缺失、市场空态判定顺序错误、引导进度刷新即丢、启动文档与实际不符（Node 版本、dev 装载地址）。

## Solution

按三个批次把巡检发现全部收口：

- **P0 批（断点批）**：修复流式响应的 CORS 头让 AI 通路打开；在 daemon 实现真实的「本地建议」生成器，让降级态有名有实；步骤流与全部 AI 文案对齐现实；命令面板样式接入 + ⌘K 全局键位。
- **P1 批（快赢批）**：MCP 审批终态留存；错误面中文化（人话 + 下一步 + 可折叠技术详情与错误码）；禁用原因 tooltip 补齐；版本恢复 Toast 带「撤销」；新建对话框 Esc；环境文档与水合警告修复。
- **P2 批（交互缺口批）**：图层拖拽排序、重命名反馈与钳制、行内显隐/锁定、标尺参考线、双击文本编辑、Token 添加入口、市场判定顺序与空态、编辑器内市场面板入口、最近使用分组、引导进度持久化。

全部改动遵守既有验收口径：全中文文案（ADR-0003）、双层验收（ADR-0005）、术语表纪律。

## User Stories

1. 作为新用户，我想让首页的 AI 入口诚实描述它能做什么，以便我不对「生成图层」抱错误预期。
2. 作为 AI 功能用户，我想在提交前知道当前是降级态还是在线态，以便决定是否等待。
3. 作为 AI 功能用户，我想在降级态得到可用的本地建议（而非空结果），以便没有 key 也有交付物。
4. 作为 AI 功能用户，我想明确知道本地建议不是大模型输出，以便不误判内容来源。
5. 作为 AI 功能用户，我想区分五种失败原因（未配置/上游错误/超时/限流/响应异常），以便采取不同动作。
6. 作为 AI 功能用户，我想看到失败原因的中文人话与下一步（如「去配置 key」「重试」「去诊断」），以便自救而不是死循环重试。
7. 作为 AI 功能用户，我不想看到并未发生的「校验/编译」打勾，以便信任剩余的状态指示。
8. 作为 AI 功能用户，我想在生成进行中取消任务，以便不干等。
9. 作为编辑器用户，我想让保存失败、连接失败显示中文原因与可执行下一步，以便不猜英文报错。
10. 作为编辑器用户，我想在错误详情里看到错误码（可折叠），以便报障时可引用。
11. 作为审批人，我想在确认或拒绝 MCP 提案后看到持久的终态反馈，以便确认决策已被记录。
12. 作为审批人，我想在提案过期时知道下一步由谁重新发起，以便不被丢在断点。
13. 作为 MCP 调用方用户（经 ZCode/WorkBuddy 驱动设界），我想让提案处理后有可见结果，以便形成闭环。
14. 作为键盘用户，我想在任意页面用 ⌘K 呼出命令面板，以便获得统一入口。
15. 作为键盘用户，我想让命令面板以居中卡片加遮罩呈现，以便不与画布内容混淆。
16. 作为键盘用户，我想在面板中看到最近使用的命令，以便加速高频操作。
17. 作为键盘用户，我想让长按修饰键的速查卡出现在视口内，以便真正可用。
18. 作为编辑器用户，我想在图层面板拖拽排序，以便按我的心智组织图层。
19. 作为编辑器用户，我想在图层重命名为空时得到提示并回退，以便不产生无名图层。
20. 作为编辑器用户，我想让图层名超长时被钳制（与新建文件一致的上限），以便面板可读。
21. 作为编辑器用户，我想在图层行直接切换显隐与锁定，以便快速管理。
22. 作为编辑器用户，我想从标尺拖出参考线并可删除，以便精确对齐。
23. 作为编辑器用户，我想双击画布文本直接进入内联编辑（Esc 取消、失焦提交），以便所见即所得。
24. 作为编辑器用户，我想让 Token 有添加与管理入口，以便资产面板不只是只读。
25. 作为市场用户，我想在空索引下搜索时看到「无结果」而不是「索引缺失」，以便理解真实原因。
26. 作为市场用户，我想让「已装载」视图与索引缺失区分空态，以便知道该去采集还是从未装载。
27. 作为市场用户，我想在编辑器内直接打开市场面板，以便不离开画布检索资产。
28. 作为数据看板用户，我想在空态里直接看到采集命令提示，以便照着跑通采集线。
29. 作为编辑器用户，我想让禁用的按钮悬停时解释原因，以便知道如何解锁。
30. 作为编辑器用户，我想让恢复版本后的 Toast 带「撤销」动作，以便误恢复一键回退。
31. 作为新用户，我想让新建对话框提交失败后 Esc 可以关闭，以便不卡在对话框里。
32. 作为新用户，我想让四步引导的进度在刷新后保留，以便中断后不从头再来。
33. 作为接手开发者，我想让 README 的启动要求准确（daemon 的 Node 版本要求、dev 装载地址），以便第一次就跑起来。
34. 作为接手开发者，我想让编辑器路由的 hydration 警告与 script 标签警告清零，以便真问题不被控制台噪声淹没。
35. 作为编辑器用户，我想让 Inspector 的效果名等文案与诊断面板日志走中文目录且不重复告警，以便界面语言一致可信。

## Implementation Decisions

**批次与优先级**：P0 = 断点批（CORS、AI 诚实化含真模板、命令面板）；P1 = 快赢批（MCP 终态、错误中文化、tooltip、Toast 撤销、Esc、环境与警告）；P2 = 交互缺口批。批次内各项相互独立，可并行领取。

**P0-1 流式响应 CORS（断点一）**：daemon 的 SSE 响应头必须由与普通响应**同一个 CORS 策略对象**生成——流式写头时合并策略头部，不再绕过 onRequest 钩子。白名单语义（本机开发来源 + `Origin: null`）、`vary: Origin`、预检短路、600s 预检缓存全部不变；非白名单 Origin 仍「不加放行头、API 语义不变」。修复后 AI 抽屉的未配置态应走完四步并呈现降级结果，而非传输错误。

**P0-2 本地建议生成器（断点二·实现真模板）**：daemon 侧新增**纯函数**生成器：输入用户提示词，输出结构化的中文建议（识别按钮/颜色/圆角/布局/文本等关键词族，给出分步操作建议与注意事项）。约束：

- 输出走既有 AI 契约（content + suggestions），**不产出 Design IR、不触碰命令栈**——那是 P5 网关的边界；
- 生成器**确定性**（同输入同输出），便于门禁与测试断言；
- 结果在 UI 上以独立角标明确标注「本地建议 · 非 AI 生成」，与在线结果视觉同构但来源可辨；
- 与 P5 的重叠风险已被接受：P5 落地时生成器降级为「上游不可用时的兜底」，接口不变。

**P0-3 AI 文案与步骤诚实化（断点二）**：步骤流收敛为「排队 → 模型生成 → 完成」三段；「校验/编译」从 UI 移除，但保留在契约与状态机中作为 P5 的扩展位（接入时恢复渲染）。`degradedReason` 五类映射为中文人话文案（i18n 目录）。以下文案统一改到与实际交付一致：首页 AI 区（不再承诺「初稿与图层结构」）、抽屉副标题、设置页降级提示、「本地模板」角标及其说明。verify-ai-two-state 门禁与步骤收敛**同票同改**（门禁断言的时序 = 用户看到的时序）。

**P0-4 命令面板（断点三）**：接入既有面板样式（居中卡片 + 遮罩 + 速查卡入视口）；⌘K 注册为全局键位（首页/设置/编辑器均可呼出），编辑器保留 ⌘/ 作为别名（与快捷键说明表同步）；新增「最近使用」分组（本地记录最近执行的 5 条命令，不联网）。长按速查卡的位置缺陷随样式修复一并收口。

**P1-1 MCP 审批终态留存**：ack 完成（批准/拒绝/失败）后确认条进入终态并保留，直至新提案替换或 TTL 到期；一次性 token 语义、审计字段、桩角标全部不变。

**P1-2 错误面中文化**：网络层失败（fetch 型错误）统一映射为「中文人话 + 可执行下一步 + 可折叠技术详情（含错误码）」，覆盖 AI 抽屉、顶栏保存态、市场错误态三面。人话示例口径：「无法连接本地服务——请确认 daemon 已启动」，技术详情保留原始 message。全部文案入 zh-CN 目录（ADR-0003）。

**P1-3 禁用原因补齐**：复用既有按钮的禁用原因机制（「分享」已有），为撤销/重做、AI 生成、生成图片、「从模板新建」补齐悬停原因。

**P1-4 Toast 撤销**：恢复版本的 Toast 附「撤销」动作，复用顶栏撤销的**同一条命令 id**（入口不漂移纪律）。

**P1-5 新建对话框 Esc**：提交失败后焦点回到对话框内首个非法字段（或对话框容器），Esc 恢复生效；与既有删除确认框行为对齐。

**P1-6 环境与警告**：README 修正 daemon 的 Node 版本要求（22.16 需显式开启类型剥离，或声明 ≥22.18）；dev 装载地址统一为 localhost（或为 dev 服务器配置允许的开发来源，二选一，实现票裁决）；消除编辑器路由的 data-theme 水合错配（服务端与客户端首帧一致，或显式豁免该属性）；定位并消除「script tag while rendering」React 警告与诊断面板重复 key 警告；Inspector 未翻译键（如效果区原始键名）补齐 i18n。

**P2 交互缺口批**：

- 图层：拖拽排序（走命令栈事务，可撤销）；空名重命名给提示并回退；名称长度钳制到与新建一致的 64 字符；图层行内显隐/锁定控件。
- 画布：从标尺拖出参考线（参考线入页面数据、可删除、参与吸附）；双击文本进入内联编辑（Esc 取消、失焦提交、超长输入钳制）。
- 资产：Token 的添加/管理入口（组件系统仍不在本 spec）。
- 市场：判定顺序修正——有查询词时无结果空态优先于索引缺失提示；「已装载」视图与索引缺失区分空态；排序状态计入筛选（「清空筛选」语义一致）。
- 看板：空态内提供采集命令提示（与市场首页空态同源）。
- 编辑器内市场面板：以槽位注册方式给 `/market/panel` 已有面板一个编辑器内入口（左栏或资产页签扩展，实现票裁决）。
- 引导：四步进度本地持久化（刷新/后退不丢）。

**验收口径**：对标页改动按 ADR-0005 双层验收（结构布局断言 + 视觉等价 + 体验验收）；自设计页按设计系统一致性；新文案违反术语词表 = A 级缺陷。

## Testing Decisions

**好测试的标准**：只测外部行为——DOM 挂点属性（data-df-*）、i18n 渲染输出、HTTP 头与信封、纯函数输入输出；不测内部实现细节。

**接缝（全部为既有接缝，不新增）**：

1. **daemon 路由层**：AI 路由测试已有流式响应的 content-type 断言手法（inject），SSE 的 CORS 头断言加在同一处——白名单 Origin 必须看到放行头、非白名单必须没有；本地建议生成器在该层做端到端信封断言。
2. **纯函数层**：步骤状态机、确认状态机、匹配器已有纯测先例；本地建议生成器为确定性纯函数，用表驱动断言（关键词族 → 建议结构），并断言「同输入同输出」。
3. **组件层**：jsdom + testing-library 既有手法（AI 抽屉、MCP 确认条、面板均有测试文件）——断言文案、焦点管理、终态留存、tooltip、⌘K 注册表、Toast 撤销动作。
4. **浏览器门禁挂点**（e2e:smoke / verify-canvas 模式，现为挂点）：命令面板居中卡片与遮罩（计算样式）、全局 ⌘K、图层拖拽、参考线、双击文本——断言 data-df-* 挂点与可见行为；jsdom 不加载外部 CSS，面板样式回归必须落在浏览器挂点。

**门禁同改纪律**：步骤收敛与 verify-ai-two-state 同票同改；新文案与令牌受 guard:tokens / guard:vocab 既有约束；本 spec 不改 verify:perf / verify:motion 的阻塞语义。

## Out of Scope

- **AI → Design IR 编译、真实写事务、审批网关**（P5）：本 spec 只让降级态真实、传输通、文案诚实；「生成即改文档」留待 P5。
- **组件/变体系统（C17，N 项）**：创建组件/实例/变体入口不在本 spec。
- **市场数据生产（D4，N 项）**：采集/评分/索引的内容运营与装载流程实测，依赖真实数据，不在代码修复范围。
- **ComfyUI 实机路径（F5）**：进度条/取消/OOM 降档的验收依赖真实出图服务；本机无服务，相关项维持「未观察到」，不在本 spec。
- **A 区 15 项**（主窗口壳/标签栏等）：按清单口径属 P6 参照。
- **桌面壳 parity 与 Electron 相关门禁**。
- **术语改名**（ADR-0005「B 层」与验收标准「B 级」同名不同义）：另行裁决，不在本 spec。
- **未实现门禁的落地**（verify:flows / verify:states / verify:a11y 等）：另票处理。
- **在线 AI 成功路径的体验调优**：无真实 key 无法验收，留待凭据可用后另评。
