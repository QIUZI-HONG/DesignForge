## 0. 目标与决策口径

### 0.1 目标

把「功能正确但体验像演示件」的前端，改造为手感/视觉/流程/反馈四维达标的产品级前端。**保架构重实现**：feature 域、插槽注册、会话-引擎分离不动；域内重写、收过度间接层；engine/contracts 不动。

## 1. 静态走查发现（本机已证实，含证据锚点）

### F-1【缺陷】全部组件动效静默失效（「手感差」第一根因）

- `packages/ui/src/tokens.ts:458-461`：序列化器「数字默认补 px」；`:181` 时长档为纯数字 `duration: { fast: 150, base: 200, slow: 300 }`；
- 落盘 `packages/ui/src/tokens.css:47-49` 为 `--dfg-duration-fast: 150px`（应为 `ms`）；
- `packages/ui/src/components.css` 中 `transition: … var(--dfg-duration-fast) …`、`animation: dfg-menu-in var(--dfg-duration-fast) …` 等**整条声明非法**，浏览器静默丢弃 → 菜单/弹窗/抽屉/Toast 入场动画、悬停过渡全部不存在；
- `tokens.test.ts` 断言 TS↔CSS 一致——两边一致地错，**单位合法性无门禁**。
- 修法：时长档进「ms 后缀」序列化分支 + `guard:tokens` 增加单位合法性断言 + 一次全动效生效冒烟。改动极小、手感收益最大，列为阶段 0 第一票。

### F-2 令牌底座其实不差，问题在「生效」与「覆盖面」

阴影（sm/md/lg/popover 双主题）、缓动（standard/emphasized/exit）、时长档都已定义（`tokens.ts:404-419,181`）；19 个基础组件 + 六态状态族登记 8 族。**底座词汇表存在，但一半词汇（动效）因 F-1 从未生效**，且组件覆盖面窄（无树控件、数值步进/scrubbing 控件、色板、字号选择器等编辑器刚需件）。

### F-3 样式双轨制（结构一致性风险）

`packages/ui` 组件走 CSS 文件，而应用层（如 `features/ai/components/styles.ts`）走**内联样式对象 + cssVar()**。两轨都守令牌纪律，但：动效书写方式不同（CSS animation vs 内联无伪类能力）、主题切换路径不同、review 心智负担大。改版应收敛为单一轨道（建议：编辑器域重写时统一回 CSS/组件类，内联对象仅保留几何计算场景）。

### F-4 过度间接层（「结构差」的实证）

`app/editor/page.tsx:1-27` 自述：因 SSR hydration 顺序问题，插槽注册靠 `return null` 的 `<WorkspaceBootstrap />` / `<ReviewBootstrap />` 引导件 + 各票自挂载模块。这是「为绕过框架约束堆的间接层」，注册时序脆弱（注释自述「实测入口仍禁用」的坑）。改版收口：统一的客户端入口引导（一个 bootstrap、声明式注册表），删掉散点挂载。

### F-5 快捷键有地基、无产品化

`features/editor-shell/shortcuts/`（matching/use-global-shortcuts）已实现，但无命令面板（Quick Actions）、无键位速查卡——用户可发现性为零。《对标报告》P-2 建议维持有效，升为阶段 1 票。

### F-6 反馈体系只有零件、无体系

空态（EmptyState）/错误（ErrorState）/加载（LoadingOverlay/Skeleton/Spinner/Progress/Toast）组件都在（`packages/ui/src/components/`），但登记的状态族仅 8 族（`state-families.ts`），页面级「四态覆盖矩阵」（每页×空/载/错/成功）从未盘点——这是 B 层体验验收的核心待建物。

## 3. 双层验收设计（ADR-0005 的落地方案）

### A 层：结构布局断言（对标页）

- **做法**：放弃「全页像素差异率 ≤0.1%」作通过线，改为 **DOM 几何快照断言**——对每个对标页定义布局锚点集（面板几何、工具栏位置、画布视口、HUD 元素），Playwright 取 `getBoundingClientRect` 快照与冻结基线比对（阈值±2px）。
- **理由**：几何断言对「设计超越」不敏感（允许更好看的按钮），对「布局漂移」敏感（面板错位逃不掉）；且无渲染噪声，比像素对照稳定。
- 像素对照**降级为诊断工具**（不再拦合并，只产出差异热图供人工 B 级验收参考）。
- 落点：`verify:figma-*` 系列改造成 `verify:layout-*`；`acceptance-standard-v1` 升 v2。

### B 层：体验验收（新增）

| 维度 | 指标 | 门禁挂点 |
| --- | --- | --- |
| 手感·动效 | 关键流转动画**实际生效**断言（getComputedStyle 读 animation/transition 时长且 ≠ 0——F-1 的回归守卫） | `verify:motion` |
| 手感·流畅 | 交互帧率/首帧/撤销延迟（指标沿用《对标报告》§4 M1-M4） | `verify:perf` |
| 流程 | 关键动线任务步数与可达性清单（§2.2 动线区 → 每条 ≤N 步断言） | `verify:flows` |
| 反馈 | 四态覆盖矩阵覆盖率（页面×空/载/错/成功，目标 ≥90% 登记） | `verify:states` |
| 可达性 | 焦点可达 + 画布读屏替代表述（Issues #100，v1.1 收编） | `verify:a11y`（挂点） |

> 新增 B 层门禁一律按项目三态退出码纪律接入：无实现时 `exit 2` 显式阻塞，禁假绿。

## 5. 设计超越范围 v0（待动态体检定稿，逐项登记生效）

1. 动效语言：面板/浮层/抽屉出入场 + 悬停过渡全量生效（F-1 修复即达成，属缺陷修复非超越）。
2. 海拔体系应用：浮层统一 shadow-popover、弹窗 shadow-lg（现状已有令牌未成体系使用）。
3. 焦点环：全组件统一可见焦点态（键盘可达性优于 Figma）。
4. 骨架屏：市场/首页列表加载用 Skeleton 而非空白等待。
5. 命令面板（`Cmd+/`）：全命令可达 + 中文模糊搜索（Figma Quick Actions 对标+超越）。
6. 数值 scrubbing：Inspector 数值输入框拖拽改值（Figma 有；实现质量目标=超越其发现性）。
7. 快捷键速查卡：长按 `Cmd` 显示浮层提示。
8. 空态插画与引导文案：中文语境定制（ADR-0003 全中文口径的延伸优势）。
9. 可达性：画布内容的读屏替代表述与焦点管理（与 Issues #100 联动，P2 起步；v1.1 收编）。

## 7. 风险

1. **超越变漂移**：设计超越逐项登记制是唯一防线——门禁拦未登记差异，§5 清单是登记簿。
2. **门禁全红过渡期**：阶段 4 前浏览器门禁维持显式 `exit 2`（禁假绿纪律不变）；非浏览器门禁全程全绿。
3. **样式双轨迁移顺序**：先单轨化（阶段 1）再域重做（阶段 2），反过来会做两遍。
4. **P-6 矢量路径不进本总纲**：属功能空地非体验改造，留在《对标报告》P2-P3 段位，避免改版范围失控。
