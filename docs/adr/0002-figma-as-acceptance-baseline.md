# ADR-0002 · 验收基准 = Figma 本体（真实产品界面）

日期：2026-10-15
状态：已生效

## 背景

毕设要求类 Figma 产品的界面与交互尽量与 Figma 一致（全中文界面）。此前存在三套基准候选：① Figma 官方 UI3 的深色复刻（v3 原型）；② 用户提供的一张 Figma 本体截图（浅色「最近」页）建立的浅色基准（v4 原型）；③ 用户自绘一套完整设计稿。事实核实：用户 Figma 账号内并无自绘设计文件。

## 决策

**验收基准 = Figma 本体（真实产品）的界面**：由「Figma 本体页面盘点与参照采集」（寻路图 #2）建立逐页参照截图集，一切页面级对照以该参照集为准。用户自绘设计稿不作为基准。

## 后果

- 基准是「活的产品」：须冻参照集（版本 + 日期 + 哈希）才能稳定对照——细则归寻路图 #7。
- 无 Figma 对应物的页面（如市场页）不适用逐页逐像素对照——按「自设计页」口径另定（#6/#7）。
- 中文字形差异以「视觉等价」登记（Noto Sans SC 先例），不苛求像素等价字形。
