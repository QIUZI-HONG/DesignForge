# ADR-0001 · 全新重做，旧实现冻结为 DesignForge-legacy

日期：2026-10-15
状态：已生效

## 背景

2026-10-11 至 10-13，`QIUZI-HONG/DesignForge` 仓库上已有一次完整实现（产品名 DesignMind Studio）：类 Figma 在线协同设计工具——M0+M1（单人画布）、M2（实时协同：房间/只读链接/快照回滚）、M3（AI 生成 + ComfyUI 出图）全部落地，12 条浏览器验收门禁全绿。

10-14 至 10-15，毕设方向重构为「设界」：本地优先（弃在线协同）、受控 AI 写入、GitHub 大数据技能市场、MCP 双端接入；架构与旧实现的关键决策相反（协同不做、服务端改为本地 daemon、渲染改 CanvasKit、TS 全栈）。

## 决策

1. **全新重做**：按《DesignForge-架构设计说明 v1.1》从 P0 重新起步。本地工作副本（含备份）已于 2026-10-15 由用户知情全量清空，重做从零。
2. **旧实现冻结**：原仓库改名 `DesignForge-legacy`（private，描述标注「已冻结 · 只作历史」），代码与 60 张 issue 原样保留，**不迁移、不并入**；其工程文化（门禁/证据/工作树纪律）以只读方式参考。
3. **新仓起点**：`QIUZI-HONG/DesignForge`（public）承载新寻路图与新代码。

## 后果

- **损失**：M2 实时协同与 M3 的部分工程资产不直接继承（相关工作重来）。
- **收益**：架构一致性（本地优先贯穿全链）、clean-room 口径干净（不背历史包袱）、文档与代码对齐。
- **不可逆点**：被删的本地副本与备份不可恢复（用户知情选择）；GitHub 旧仓可回看，但「继续演进旧线」不在计划内。
