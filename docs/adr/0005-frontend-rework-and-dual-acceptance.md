# ADR-0005 · 前端整体改版与双层验收

日期：2026-10-24
状态：已生效

## 背景

P0 前端已通过像素级对照验收（`docs/quality/test-report-v1.md`：2756 用例全绿、54 页对照清单），但作者判定产品体验不足，四维痛点：交互手感差、视觉精致度不足、流程与反馈差、前端代码结构差。两者不矛盾：单一像素门禁只锁「静态外观与 Figma 截图一致」，锁不住手感/流程/反馈/性能。

静态走查发现机械根因：动效时长令牌落盘为 `150px`（`packages/ui/src/tokens.css:47-49`）而非 `150ms`（序列化器数字默认补 px，`packages/ui/src/tokens.ts:458-461`），导致 `components.css` 中所有引用时长的 `transition/animation` 声明非法被浏览器丢弃——**全部组件动效静默失效**；`tokens.test.ts` 只断言 TS↔CSS 一致，两边一致地错，单位合法性无门禁。

「整体改版」与 ADR-0002 的「逐页逐像素对照」口径冲突，需裁决。

## 决策

1. **UI 层整体改版，保架构重实现**：feature 域划分、插槽注册、会话-引擎分离的总体架构保留（经摸底判定架构干净）；域内实现重写并收纳过度间接层；`@dforge/engine` / `@dforge/contracts` 不动。
2. **验收改双层**：
   - **A 层（对标页结构验收）**：像素断言降级为**结构布局断言**（面板几何/尺寸/位置/栅格锚点），像素差异率不再作为通过线；
   - **B 层（体验验收）**：手感/流程/反馈/性能指标，定义见 `docs/plan/frontend-rework-v1.md` §3。
   - 视觉差异走既有 B 级「视觉等价」人工验收（`docs/spec/acceptance-standard-v1.md` 既有口径）。
3. **允许设计超越**：对标页上**登记在册**的、有意优于 Figma 本体的视觉/交互差异合法；未登记差异视为漂移，由门禁拦截。
4. **参照集重新冻结**（版本递增、更高保真）作为 A 层口径切换点；过渡期浏览器门禁显式 `exit 2` 阻塞（禁假绿）。

本 ADR 部分修订 ADR-0002：基准仍是 Figma 本体，但「逐页逐像素等价」调整为「结构布局等价（A 层）+ 视觉等价人工 + 体验层（B 层）」。

## 后果

- `docs/spec/acceptance-standard-v1.md` 升 v2：结构布局断言口径 + 体验验收层。
- GLOSSARY：「对标页」定义更新；新增「设计超越」术语。
- 时长令牌单位 bug 按**缺陷**立即修复（不属设计超越范畴）；`guard:tokens` 增加单位合法性断言，防同类静默失效复发。
- 设计超越逐项登记制：每项差异须登记于改造总纲 §5 清单后方可实施。
- 改版期间非浏览器门禁（lint/typecheck/test/guard）维持全绿纪律不变。

## 补记（2026-10-24，v1.1 勘误时增）

「参照集重新冻结（更高保真）」的用途澄清：重冻结参照集**不用于** A 层结构布局断言——几何断言基于 DOM 快照，不依赖截图。其用途是 B 级视觉等价人工验收的对照物，以及像素诊断工具（降级后不再拦合并）的基线。双层验收的实现方案见《前端改造总纲 v1》§3，与本 ADR 互为引用。
