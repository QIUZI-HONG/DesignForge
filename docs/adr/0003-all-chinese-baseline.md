# ADR-0003 · 全中文基线（界面、术语与字体）

日期：2026-10-15
状态：已生效

## 背景

项目服务于国内高校的毕业设计（中文答辩、中文演示、中文论文），用户在 2026-10-15 明确定调：「项目要全中文，因为是国内的高校」。此前中文化词表（21 条，ODS 时期）散落各处且未与对照基准校准；字体问题经对照工具链研究（#5）暴露：本机无任何 Noto 字体、CJK 靠系统 `msyh.ttc` 兜底且声明缺失会静默回退，而字形差异的像素量级（5398px）大于真实布局回归（3722px）——字体不钉死，像素级验收不可用。

## 决策

1. **界面语言：全中文且唯一暴露**——不提供语言切换入口；i18n 架构保留 en 兜底仅作工程回退（缺翻译兜底），不作为可切换界面语言。文档、票、证据、报告一律中文。
2. **术语**：以 **Figma 本体中文界面的实际用词**为「同物同词」的校准源；21 条对照表为基线，逐条与 Figma 中文界面校准后生效（不一致处从 Figma）。界面文案违反词表 = A 级缺陷。
3. **字体**：实现侧**捆绑 Noto Sans SC**（思源黑体系，SIL OFL 开源，`@fontsource` 离线安装，可子集化）；对照中字形差异一律按「视觉等价」登记（B 级）；验收门禁必须断言字体已加载（禁止静默回退）。
4. **对照语言面**：参照集 = Figma 本体**中文界面**截图（与实现侧同为中文语境的对照）。

## 后果

- 验收的文本面完全落入 B 级（掩膜 + 人工），A 级聚焦几何与颜色——判定线因此更清晰（见《前端验收标准 v1》）。
- 字体进包，体积增加（子集化后可控）；离线渲染确定性增强。
- 不再需要英文文案评审；保留 i18n 兜底带来少量工程复杂度（可接受）。
