# 前端范围与依赖边界 v1（设界 · 寻路图 #6）

- 状态：**v1 定稿**（2026-10-15，#6 收口）
- 输入：Figma 本体页面盘点（研究 #2，76 项清单草案）、《前端验收标准 v1》（#7）、设界架构说明 v1.1
- 用途：约束「对照页面与弹窗清单定稿」（#8）与「前端实现规格」（#11）；本文档为《前端验收标准 v1》**附录 C** 的来源

## 1. 判定

本轮（起步段）的「前端」= 设计工作台的**全部界面与基础编辑行为** + **技能市场及其数据面**。范围判定原则：白名单功能域内与 Figma 本体同构者收为**对标页**；设界自有页面（市场/看板/引导）收为**自设计页**；Figma 平台矩阵与云侧能力整体不入。

## 3. 依赖真 / 桩矩阵

| 依赖 | 姿态 | 口径 |
|---|---|---|
| 编辑器内核（自研 TS：场景图/命令栈/布局/组件/Token/命中） | **真** | 交互白名单 13 类可用；性能硬指标（500 节点 ≥55FPS 等）另立 P1 基线，**不入本段验收判据** |
| 本地 daemon（Fastify，v1.1 §4.2 子集） | **真** | 文档/导出/AI 代理/出图调度/凭据/市场服务/本地遥测；不含 MCP 网关 |
| AI 文本（DeepSeek，BYOK） | **真 + 降级分支必验** | 无 key / 失败 → 本地模板与建议清单（US-21）；两态均进验收 |
| 出图（本地 ComfyUI） | **真 + 两态必验** | 正常态 + 未启动/缺模型态（提示与动作）；mock 仅开发辅助 |
| 市场数据 | **真** | 采集线首实现（#10）供数；空态/错误态同验 |
| MCP 确认条（F9） | **桩** | 按 v1.1 §4.5.4 契约形状 mock（dryRun → ackToken → 审计）；MCP 网关 = P5，不在本段 |
| 云汇聚 / 遥测上云 | **不进** | 埋点默认仅本地（真） |
| 实时协同 / 更新通道 / 多标签壳 | **不进** | 圈外与 P6 缓归 |

## 4. 达标语义

- 「达标」= 《前端验收标准 v1》**全条款通过**：54 项逐项按 A/B 级判定 → 差异全闭环（差异 → 修复 → 复核 → 关闭）→ 功能点逐项**双签**（断言脚本 + 验收会话）→ 出具《前端验收结论》。
- **桩依赖（MCP）必须在结论与演示口径中显式标注**。
- 不构成本段判据：性能硬指标、移动端编辑、P6 体验项（多标签壳/错误分类/更新通道）。

## 5. 界定外（经此票确认）

- Figma 平台矩阵（Make / Sites / Slides / Motion / FigJam / Buzz / Specs）与云协作概念（团队 / 分支 / 通知 / 账号）。
- 多人实时协同（v1.1 Non-goal；「本地双窗只读演示」为可选演示项，不进验收）。
- P0 骨架中超出「前端 + 市场」所需的部分（daemon 握手全量、更新通道、四守卫全量 —— 见 #13 圈外条目）。
