## 术语对照（附录 B 程序）

- 校准源 = **Figma 本体中文界面实况**（ADR-0003）；21 条基线为底，逐条校准、不一致从 Figma。
- 已确认示例：Frame→画板、Auto Layout→自动布局、Override→覆盖、Variables→变量、Inspect→检查、Dev Mode→开发者模式（其余条目随参照集采集时逐条登记补齐并终审）。
- 校准动作归属：参照集采集会话（随采集一次完成）；界面文案违反词表 = **A 级缺陷**。

## 参照集采集要点（引研究 #2 §2.3）

- 基准视口 1440×900 逻辑、DPR 1.5 高清抓取；命名 `figma-<区段>-<ID>-<名称>-<主题>-<状态>.png`；浅/深双版；截图存**仓库外**；用空白/演示文件截图（隐私）。
- 主路径：桌面端/浏览器已开页面 → WSL PowerShell 截屏（脚本已实测）；自动切页受限 → 用户配合为兜底。
