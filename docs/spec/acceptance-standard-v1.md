# 前端验收标准 v1（设界）

- 状态：**v1 定稿**（寻路图 #7 收口，2026-10-15）
- 依据：用户验收口径（逐页/逐组件/逐元素；布局·样式·间距·颜色·字体·交互状态一致）＋ ADR-0002（基准 = Figma 本体）＋ ADR-0003（全中文基线）＋ 研究票 #2（页面盘点）/#5（对照工具链）
- 适用：设界前端全部页面与弹窗；对照页走 §2–§5，自设计页走 §6。

## 1. 总则

1. **对照面**：逐页 → 逐组件 → 逐元素；每个元素核 **布局、样式、间距、颜色、字体、交互状态** 六个维度。
2. **基准**：Figma 本体（**中文界面**）的真实渲染；参照集逐页冻结（版本号 + 日期 + 截图哈希），冻结后不得更换。
3. **全中文**：界面文案全中文且唯一暴露（无语言切换）；术语以 Figma 本体中文界面用词为准（21 条对照表校准后生效）；违反 = A 级缺陷。
4. **判定分级**：A 级 = 像素级（自动断言）；B 级 = 视觉等价（人工复核 + 登记表）。

## 2. 判定分级表

| 维度 | 级别 | 判定方式 |
|---|---|---|
| 布局 / 几何（位置·尺寸·间距·圆角·层序·对齐） | A | 截图 diff（pixelmatch，threshold=0.1）＋ 几何断言（包围盒 / 间距采样） |
| 颜色（填充·描边·背景·关键色） | A | 像素比对覆盖 ＋ 关键色采样断言（同色值目标） |
| 图标（几何·尺寸·描边·颜色） | A | 自绘 SVG（clean-room）；几何断言；图标形状细节按 B 级（视觉同族） |
| 文本字形（中文字形·断行·字重） | B | 区域掩膜 ＋ 人工复核（视觉等价登记，ADR-0003） |
| 抗锯齿 / 滚动条 / 光标 | B | 掩膜 / 人工 |
| 动效与过渡 | B | 取终态自动 ＋ 人工评估（自动截图只取终态） |
| 阴影 / 模糊质感 | B | 人工复核 |
| 页面整体 | A | 页面级差异像素率 ≤ 0.1%（B 级区域掩膜后）；实现期按真实页面校准一次，**只许收严不许放宽** |

## 3. 对照基准参数

- **视口**：1440×900 CSS 逻辑（主基准）；采集 DPR = 1.5（本机 150% 缩放下高保真档，物理 2160×1350）；**两侧同一 DPR**，尺寸守卫强制一致；禁用 1× 降采样基准（模糊伤像素判定）。
- **主题**：**逐页对齐 Figma 本体**——首页/文件浏览器类 = 浅色，编辑器 = 深色（UI3）；不做全站统一换肤；每个对照页在其对应主题下比对（v3 深色 / v4 浅色之争就此消解：各归其页）。
- **字体**：实现侧捆绑 **Noto Sans SC**（SIL OFL，@fontsource 离线）；门禁断言字体已加载（禁止静默回退）；字形差异 B 级。
- **断点**：1440×900 主基准；1280×800 / 1024×768 窄窗「不破版」（可用、无溢出遮挡）；移动端编辑端不做（与 Figma 本体一致；如需移动演示另议）。
- **运行环境**：同一 web 产物在浏览器与 Electron 壳（webview）内均须一致（壳内截图与浏览器截图同容差比对）。

## 4. 流程与闭环（可跟踪、可闭环）

1. 参照集冻结（逐页截图 + 元数据：版本 / 日期 / 哈希）。
2. 实现侧逐页截图（工具链：playwright-core 1.63.0，锁缓存 chromium-1243）。
3. 自动 diff + 断言 → 差异清单：**每项差异 = 一条 issue**（含页面 / 位置 / 级别 / 证据）。
4. 修复 → 重新比对（同一参照集）→ 复核 → 关闭 issue。
5. 全部关闭后出具《前端验收结论》（含证据索引与遗留登记表）。

- 证据 JSON 字段（沿用研究 #5 草案）：`page / level / diff.bbox / diffPixels / ratio / artifacts{ref,actual,diff: {sha256,length}} / humanReview{verdict,reviewer,reason} / exitCode(0/1/2)`。
- 门禁家族：`verify-figma-page / -component / -states / -baseline`；基线哈希校验与几何断言进 CI，像素绝对阈值本地受控跑。

## 5. 状态覆盖清单（每个对照页逐项取证）

hover / active（focus-visible）/ disabled / loading（骨架与进度）/ empty / error —— 覆盖缺项 = 缺陷（影响布局者按 A 级）。

## 6. 自设计页（无 Figma 对应物：市场页、数据看板等）

- 不逐像素对照；改走三类检查：①设计系统一致性（令牌 / 组件 / 密度 / 栅格）；②状态覆盖（同 §5）；③与相邻对照页风格同族（人工 B 级）。
- 市场页另对齐《技能市场规格 v1》（#9）的交互要求。

## 7. 功能点核对

- 自动断言优先：导航 / 路由、开关状态、表单校验、加载 / 空态 / 错误态、快捷键。
- 人工清单：连续交互手感（拖拽 / 缩放 / 吸附等）→ 录屏证据。
- 「每个功能均已实现且行为符合预期」的判定主体 = 验收会话（人工）＋ 断言脚本（自动）双签。
- 后端依赖真 / 桩边界：以「本图前端范围与依赖边界」（#6）结论为附录并入。
