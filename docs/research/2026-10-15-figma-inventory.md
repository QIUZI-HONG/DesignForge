## 0. 结论（TL;DR）

1. **页面/弹窗清单草案已就绪（§1）**：按「壳 → 首页/文件浏览器 → 编辑器 → 市场 → 设置/引导/命令面板 → 浮层与状态页」6 区，共 **76 项**（含 15 项壳层、12 项首页、20 项编辑器、5 项市场、9 项设置/引导/命令面板、15 项浮层与状态页）。每项标注对标要点（布局/间距/圆角/配色/字体/图标/交互状态 7 维度）与证据来源。
2. **参照采集路径 = 三路并行，A 路已实测打通（§2）**：
   - **路径 A（WSL 调 PowerShell .NET 截屏）实测可行**：全屏 1707×1067 PNG 84ms 出图；区域截屏、指定窗口（GetWindowRect P/Invoke）均通过；DPI 感知开/关两档分别出 2560×1600 原生 / 1707×1067 逻辑像素。限制：窗口必须可见于屏幕（不能最小化），抓的是屏幕合成结果。
   - **路径 B（浏览器 figma.com）可行但有登录墙**：WSL 直连 `www.figma.com` 200/1.47s；`/files` 302 → `/login`（文件浏览器必须登录）；Windows 侧 Chrome 与 Edge 均在。桌面端 web 应用与浏览器同源（【逆】），浏览器对照与桌面端等价。
   - **路径 C（用户逐页截图）为兜底主路径**：规范与命名规则见 §2.3（1440×900 逻辑基准，截图存仓外）。
3. **深浅主题口径：事实与选项已记录、未作决定（§3）**。事实：Figma 本体首页/文件浏览器为**浅色**（v4 基准来源），编辑器为**深色 UI3**（v3 基准来源）；v4 现行全站浅色 + 深色变量组保留；旧仓先例是浅/深一键切换。选项 A/B/C/D 交票 #8 决定。
4. **本票未碰任何 Figma 资产**；实测截图仅用于验证可行性，元数据记录后即删（§2.1.4）。

### 2.1 路径 A：WSL → PowerShell .NET 截屏（✅ 实测可行）

#### 2.1.1 环境事实（实测）

| 项 | 值 |
|---|---|

| 物理分辨率 | 2560×1600（Get-CimInstance Win32_VideoController） |

| Figma 进程（测试时） | 未运行（`Get-Process Figma` → none） |

#### 2.1.2 四组实测结果

| 测试 | 命令要点 | 结果 |
|---|---|---|
| 全屏截图 | `Graphics.CopyFromScreen` + `Bitmap.Save(Png)` | **通过**：1707×1067 PNG，110 KB，全屏+区域两次共 84 ms |
| 区域截图 | 指定 rect (0,0,800,600) | **通过**：800×600 PNG |
| 指定窗口截图 | `user32.GetWindowRect` P/Invoke + 按窗口 rect 抓取 | **通过**：对 ApplicationFrameHost 窗口实测 `WINDOW_RECT:-7,-7,1721x1033` 并出图 |
| DPI 感知 | `SetProcessDPIAware()` 后重抓 | **通过**：2560×1600 原生像素（未感知时为 1707×1067 逻辑像素） |

#### 2.1.3 关键结论与限制

1. **可自动化**：整条链路（WSL bash → powershell.exe → PNG 落盘 → `cp /mnt/c/...` 回 WSL）全程无窗口弹出、无交互，**可用于后台采集**。
2. **出图像素由 DPI 感知决定**，务必在采集脚本里显式选择：
   - 不感知（默认）：得到**逻辑像素**图（1707×1067），1440×900 逻辑窗口 → 1440×900 px 图（但由 150% 缩放渲染降采样而来，放大看会糊）；
   - 感知：得到**物理像素**图，1440×900 逻辑窗口 → 2160×1350 px 图（锐利，推荐做视觉比对）。
3. **限制**：(a) 截图是屏幕合成结果——**窗口必须可见、不能被遮挡/最小化**，RDP 断开锁屏时会抓黑屏【推断：未测锁屏场景】；(b) 无法凭空唤起 Figma 再切页签（要动窗口就会弹窗/自动化 UI，本票明确禁止）；(c) Windows 侧要先把图写进 Windows 路径再由 `/mnt/c` 拷回 WSL（本节脚本已按此设计）。
4. **隐私**：本次验证截图仅用于确认管道可用，记录元数据后**已即刻删除**，未入仓。后续正式采集必须遵守 §2.3.4 的内容约定。
